## Project licence — not chosen

`LICENSE` is a **placeholder** stating that no licence has been chosen ("all rights reserved" by default under copyright law).
TripoSR's MIT licence applies to TripoSR only and does **not** determine ARO 3D Studio's licence. A test
(`tests/test_repository_safety.py::test_project_licence_is_still_the_owners_decision`) fails if someone replaces the
placeholder with a licence text without updating that decision record. Note that a public repository with no licence is legally
"look but don't use": decide deliberately.

## Rules for future commits

1. Never commit model weights, `.env`, tokens, purchased/third-party 3D models, or user concept images you do not own.
2. Evidence from a GPU run may include the concept image used — commit it only if you own it or it is licensed for redistribution.
3. Add any new binary to the allow-list in `tests/test_repository_safety.py` in the same commit, with a note on where it came from.
